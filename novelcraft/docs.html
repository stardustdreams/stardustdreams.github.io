🚀 クイックスタート

NovelCraftを使って最初のノベルゲームを作るまでの流れを説明します。5分もかかりません。

💡

プログラミング知識は不要です。すべての操作はGUIで行えます。

インストール

  1. ダウンロードページから使用OSのファイルをダウンロード
  2. Windows: NovelCraft-Setup-0.9.2.exe を実行してインストーラーの指示に従う
  3. macOS: NovelCraft-0.9.2.dmg を開き、アプリケーションフォルダにドラッグ
  4. NovelCraftを起動するとホーム画面が表示されます
🏠
スクリーンショット：ホーム画面
起動直後のホーム画面 → assets/screenshots/home-screen.png に保存

最初のプロジェクト

  1. ホーム画面の「新規プロジェクト」をクリック
  2. プロジェクト名とゲームタイプを選択
  3. 保存先フォルダを選んで「作成」をクリック
  4. メインエディタが開くので「シーン1」をダブルクリックして編集開始

リソース管理

対応フォーマット:

  • 画像: PNG, JPG（背景・立ち絵・スチル）
  • 音声: MP3, OGG（BGM・SE・ボイス）
  • 動画: MP4, WebM（OP/ED・ムービー）

💬 テキスト・台詞

text — テキスト表示

キャラクターの台詞やナレーションを表示します。最も基本的なコマンドです。

パラメータ型説明
namestringキャラクター名（省略でナレーション） optional
textstring表示するテキスト required
speednumber文字表示速度 0〜100（デフォルト: 50） optional
voicestringボイスファイル名 optional
windowstringnormal / full / transparent optional
例
// キャラクターの台詞
text(name: "明日葉", text: "あなたも…ここに来るんですね")

// ナレーション
text(text: "夕暮れに染まった屋上で、彼女は一人佇んでいた。")

🖼️ 背景・演出

background — 背景変更

パラメータ型説明
imagestring背景画像ファイル名 required
transitionstringfade / crossfade / wipe / instant optional
durationnumberトランジション時間(ms) optional
例
background(image: "bg_classroom.png", transition: "fade", duration: 800)
effect(type: "shake", intensity: 5, duration: 600)

👤 キャラクター

showChara / moveChara / hideChara

例
showChara(id: "asaba", expression: "surprised", position: "right", fade: 300)
moveChara(id: "asaba", to: "center", duration: 600)
hideChara(id: "all", fade: 500)

🎵 BGM・SE・ボイス

コマンド主なパラメータ説明
playBGMfile, loop, volume, fadeInBGMを再生（デフォルトでループ）
stopBGMfadeOutBGMをフェードアウトして停止
playSEfile, volume効果音を再生

🔀 選択肢・分岐

例
choice([
  { label: "「ええ、よくここで考えごとを」", jump: "route_a" },
  { label: "「あなたこそ、何を見ているの？」", jump: "route_b" },
  { label: "「…何でもない」", jump: "route_c" }
])

if / else / endif

例
if (love_point >= 80)   jump("good_ending")
else if (love_point >= 40) jump("normal_ending")
else                      jump("bad_ending")
endif

📊 変数・フラグ

例
setVar(name: "love_point", value: 0)
setVar(name: "love_point", value: 10, op: "add")
setVar(name: "flag_met",   value: true)

⚙️ システムコマンド

コマンドパラメータ説明
waitms: number指定ミリ秒待機
jumplabel: string指定ラベルにジャンプ
labelname: stringジャンプ先ラベルを定義
save—セーブ画面を開く
load—ロード画面を開く
end—シナリオ終了
